# XCOM: A Tribute

A tribute website dedicated to the XCOM franchise, spanning 30+ years of humanity's last line of defense against alien invasion. This project covers the original Mythos Games series and the modern Firaxis era.

## Features

- **Responsive Design:** Optimized for desktop and mobile devices.
- **Themed UI:** Dark mode aesthetic with XCOM-inspired colors (orange/blue) and fonts (Orbitron/Rajdhani).
- **Interactive Elements:** Smooth scrolling, timeline animations, and hover effects.
- **Comprehensive Content:** Covers game history, mechanics, developers, and legacy.

## Getting Started

Simply open `index.html` in your web browser to view the site. No build process or server required.
